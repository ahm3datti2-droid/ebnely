# Ebnely — ابنيلي
دليل أسعار تشطيب العقارات في مصر — عربي RTL، موبايل أولاً، جنيه مصري.

## هيكل الملفات — المرحلة 1

```
ebnely/
├── index.html            ← الرئيسية: بحث + 15 قسم + زرار "احسب تكلفة شقتك"
├── category.html         ← صفحة القسم: كل البنود بأسعارها + فلتر بالمستوى
├── item.html             ← صفحة البند: كل التفاصيل (خامة + مصنعية + إجمالي)
├── calculator.html       ← الحاسبة — صفحة انتظار، الكاملة في المرحلة 3
├── admin.html            ← لوحة الأدمن (باسورد) — تعديل أسعار، بالجملة، إعدادات، طلبات
├── css/style.css         ← كل التصميم: رملي/بيج + غامق، موبايل أولاً
├── js/config.js          ← الإعدادات: اسم التطبيق، رقم الواتساب، باسورد الأدمن
├── js/data.js            ← تحميل الأسعار + دمج تعديلات الأدمن
├── js/app.js             ← كود الرئيسية (بحث + أقسام)
├── js/admin.js           ← كود لوحة الأدمن (تعديل، بالجملة، تصدير)
├── data/prices.json      ← قاعدة البيانات في المرحلة 1: 15 قسم + 45 بند بأسعار تقريبية
├── db/schema.sql         ← مخطط D1 (Cloudflare) — نفس شكل الـ JSON، جاهز للمرحلة 5
├── wrangler.toml         ← إعدادات Cloudflare Workers — المرحلة 5
├── vercel.json           ← إعدادات النشر على Vercel
├── manifest.json + sw.js ← PWA — يتسطب على الموبايل زي أبلكيشن
└── images/               ← لوجو + صورة مؤقتة للبنود
```

## البيانات — المرحلة 1
- 15 قسم، 45 بند (3 في كل قسم).
- كل بند: وحدة قياس (م² / م.ط / نقطة / قطعة / مقطوعية) + 4 مستويات (اقتصادي / متوسط / لوكس / سوبر لوكس) + خامة + مصنعية + إجمالي (من – إلى) + تاريخ آخر تحديث + ملاحظات.
- الأسعار **تقريبية استرشادية** بتاريخ 2026-11-20 — لازم تراجعها وتعدّلها من الأدمن قبل ما تعلنها للعملاء.

## لوحة الأدمن — خطوة بخطوة من الموبايل
1. افتح رابط الموقع، اضغط "الأدمن" من فوق.
2. اكتب الباسورد الافتراضي: `Ebnely2026` واضغط دخول.
3. من تبويب "البنود والأسعار": اختار القسم، عدّل سعر (من – إلى) واضغط "حفظ السعر".
4. من تبويب "تعديل أسعار بالجملة": اختار القسم، اكتب النسبة (مثال: 10 = زوّد 10%)، واضغط "طبّق التعديل".
5. من تبويب "الإعدادات": غيّر رقم الواتساب والباسورد، واضغط "حفظ الإعدادات" — **غيّر الباسورد فوراً بعد أول دخول**.
6. للنشر للكل: من الإعدادات اضغط "تصدير JSON" — هينزل ملف `ebnely-prices.json`، ابعتهولي وأنا أرفعه على GitHub وVercel في دقيقة.

ملحوظة: التعديل في المرحلة 1 بيتحفظ في جهازك فوراً وبيظهر على الموقع في نفس الجهاز. الحفظ المباشر لقاعدة البيانات لكل الزوار هيتوصل في المرحلة 4.

## النشر
- GitHub: ريبو `ebnely` — المصدر الوحيد للكود.
- Vercel: مشروع `ebnely` — مربوط بالريبو، كل دفع على GitHub بينشر تلقائياً.
- Cloudflare D1 + R2: مخطط قاعدة البيانات جاهز في `db/schema.sql` — التنفيذ في المرحلة 5.
